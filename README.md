# Dashboard Complaint Astro CX

Dashboard monitoring komplain internal Astro — cover Januari sampai minggu terkini (2026).

## Cara Akses (Tim CX & Stakeholder Internal)

1. Klik file **`index.html`** di list file atas
2. Klik tombol **Download raw file** (icon ⬇️ di kanan atas)
3. Buka folder Downloads di komputer kamu
4. Double-click file `index.html` → auto buka di browser
5. Tunggu 3-5 detik → dashboard siap dipakai ✅

## Isi Dashboard

- **Overview** — KPI cards (Orders, Complaint, Inquiry, Complaint Only)
- **Trend** — Daily & monthly complaint trend
- **Role Breakdown** — Customers, Hub Warehouse, Driver 3PL, dll
- **Tipe Complaint** — Fulfillment Accuracy, Kualitas Barang, dll
- **Hub Performance** — Complaint per hub warehouse
- **SKU Sensitif** — Top SKU by complaint
- **Action HW** — Action tracker khusus Hub Warehouse
- **Metric Summary** — Recap perbandingan bulan

## Filter yang Tersedia

- Month (Jan – Jul 2026)
- Week (W01 – terkini)
- Role, Tipe, Alasan, Impact
- Hub, Action
- Kategori L0/L1/L2
- Search SKU
